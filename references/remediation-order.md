# Remediation order

Use this sequence as a default. Reorder only when dependencies or user impact justify it.

1. **Truth and safety:** remove unsupported claims, fabricated metrics, exposed private data, broken destructive actions.
2. **Task clarity:** make the primary task, page purpose, and key action obvious.
3. **Structural rhythm:** fix information order, grouping, alignment, layout, and responsive behavior.
4. **System consistency:** normalize semantic tokens and repeated component variants.
5. **Reading quality:** repair typography, copy, contrast, and icon meaning.
6. **Data and states:** correct charts, tables, loading/empty/error/success states.
7. **Visual polish:** refine surfaces, imagery, border/radius, and restrained effects.
8. **Motion:** keep only purposeful motion and support reduced motion.
9. **Regression checks:** compare before/after at matching routes, states, and viewports.

Do not spend time perfecting shadows while a primary action is hidden or a chart is lying.

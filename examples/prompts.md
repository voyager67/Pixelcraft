# Prompt examples

## Detect only

“Use `slop-detection` on these screens. Report observable patterns, evidence, confidence, user impact, and benign explanations. Do not infer who authored the UI.”

## Audit and prioritize

“Use `slop-audit`, then `slop-severity-triage`. Do not change code yet.”

## Full redesign

“Use `unslop-ui` on this dashboard. Preserve actual functionality and source data. Inspect the rendered UI, establish a product-specific direction, then implement and verify the changes.”

## Specific patterns

- “Use `effects-overuse-repair` to remove gratuitous gradients and glow while keeping the established brand.”
- “Use `fabricated-proof-detector` to verify every metric, testimonial, customer logo, rating, and integration claim.”
- “Use `token-sprawl-repair` to consolidate duplicated CSS tokens without changing the visual identity.”
- “Use `responsive-slop-repair` to fix desktop UI squeezed onto mobile.”
- “Use `interaction-state-repair` to identify dead controls and incomplete states.”
- “Use `synthetic-image-cliche-review` to review these illustrations without claiming they are AI-generated.”
- “Use `slop-regression-review` to check whether this PR reintroduces patterns fixed in the previous cleanup.”
